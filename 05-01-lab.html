A. Ejecutar e importar un módulo

  1. Lee medidas_demo.py. Señala qué instrucciones están al nivel superior, cuáles en resumir_saldos y cuáles en main.
  2. Ejecuta python -c "import medidas_demo". Después python medidas_demo.py. Registra qué imprime cada uno y explica la diferencia.
  3. En Python o una celda importa el módulo y llama a la función con [0, 100, None, 300], [], [None, None] y [0, 1].
  4. Prueba from medidas_demo import resumir_saldos; explica qué nombre puedes usar directamente y cuál no fue incorporado por esa instrucción.
  5. Muestra medidas_demo.__name__ y medidas_demo.__file__ después de import medidas_demo. Explica para qué sirve cada dato.

Comprobación: importar no imprime la demostración. Ejecutar sí imprime el diccionario: 4 registros, 3 conocidos, mediana 100, cobertura 75 %. Evidencia: resultados y explicación de la protección de entrada.

Ver solución razonada de A

El import de statistics y las definiciones están al nivel superior. Definir main no ejecuta su cuerpo; la condición final llama main solo cuando el archivo es la entrada principal. Importar medidas_demo establece su nombre como medidas_demo, por lo que no cumple la condición.

Entrada Registros Conocidos Mediana Cobertura

from medidas_demo import resumir_saldos permite usar ese nombre sin prefijo; no incorpora el nombre medidas_demo a una sesión nueva. Si ya hiciste el otro import, ese nombre puede seguir en tu sesión: comprueba en una sesión limpia. name muestra la identidad del módulo; file su archivo de procedencia.

Ver solución razonada de B

ejecutar.py llama main del paquete; main elige rutas y llama export. El flujo lee mediante entrada, calcula con transformación, concilia con comprobación y construye figuras/informe con presentación. Las reglas compartidas viven en reglas.py. init.py no dispara ninguna de esas acciones.

read_detail recibe carpeta y devuelve detalle validado. summarize recibe detalle/fecha y devuelve detalle del corte/resumen. build_analysis recibe carpeta/fecha y devuelve cinco tablas conciliadas. export recibe además destino/resolución, escribe una carpeta nueva y devuelve las tablas.

from .entrada import read_detail parte del paquete actual; from analisis_cartera.flujo import build_analysis nombra el paquete completo. Los colores pertenecen a presentación. Fecha/fuentes se pasan al flujo; la entrada principal conserva valores iniciales por ahora. La referencia CSV calcula por un camino independiente, reduciendo el riesgo de repetir un mismo error de transformación en ambos resultados.

Ver solución razonada de C

Desde Python en la carpeta de la lección, una alternativa con destinos nuevos:

from pathlib import Path
from analisis_cartera.flujo import export

lesson = Path.cwd()
source = lesson.parents[1] / "03_sql_databases/01_relational_sqlite/data"
tables = export(source, "output/lab_modular")
rebuilt = export("output/lab_modular/fuentes", "output/lab_reconstruccion")

Comercio: mediana 3100 sobre 5/5; consumo: 1750 sobre 10/10; servicios: 2550 sobre 6/6. Las tres coberturas son 100 %. Educación conserva su categoría con ausencia de mediana. La mediana global proviene de los 21 saldos del detalle; no es una agregación de medianas.

La importación no llama export. Ambas entradas explícitas llaman el mismo main y usan la misma carpeta inicial. Si existe, mkdir con exist_ok=False detiene la escritura: conserva la entrega, pero exige elegir otro destino para una ejecución posterior. entrega.json se escribe al final; una interrupción puede dejar archivos parciales, que deben identificarse al revisar.

Las imágenes pueden variar en bytes; deben conservar valores, bases y mensajes. La revisión visual no se acredita automáticamente por la conciliación.

Ver solución razonada de D

El notebook importa build_analysis de flujo.py y delivery_figure de presentacion.py. La misma transformación interviene en ambos consumidores; el notebook muestra el resultado y no escribe otra entrega por defecto.

En un corte vacío cada segmento tiene 0 registros/0 conocidos, con mediana y cobertura no definidas. En octubre educación tiene registros y cobertura 0 %, pero sigue sin mediana. Cero conocidos no equivale a saldo cero.

Una sesión puede conservar la primera versión de un módulo importado. Reiniciar el kernel y ejecutar todo carga el archivo actual y descubre variables que antes solo existían por celdas ejecutadas fuera de orden.

Ver orientación razonada de E

Una función puede reutilizar las reglas del pequeño medidas_demo, pero debe expresar entradas/salidas y conservar el cero. La demostración llama la función solo bajo la condición de entrada. Basta un módulo para este ejercicio; crear una jerarquía de paquetes no aporta claridad por sí mismo.
