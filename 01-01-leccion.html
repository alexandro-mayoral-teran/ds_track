01.01 — Variables, tipos y operaciones

Propósito

Comprender cómo Python representa un dato y por qué su tipo cambia las operaciones que puedes realizar. Pasaremos del primer cálculo del módulo 00 a interpretar valores que podrían venir de un archivo.

Antes de empezar

Retoma el primer script y los entornos del módulo 00. Usa el entorno que elegiste, con Python y sin paquetes externos. Puedes editar en tu editor habitual y ejecutar desde la terminal. El ejemplo define sus entradas en el propio script: todavía no necesitas un CSV.

Qué vas a aprender

  • Asignar y reasignar variables, distinguiendo asignación de comparación.
  • Reconocer texto, enteros, decimales, booleanos y ausencia mediante su tipo.
  • Convertir una entrada numérica válida y explicar un error de conversión.
  • Calcular un importe en MXN y contrastarlo con una predicción manual.

1. Variables: dar nombres a los valores

producto = "cuaderno"
unidades = 3
precio_unitario_mxn = 40

= asigna un valor a un nombre. Escribe nombres que expliquen qué representa el dato; utiliza guion bajo para separar palabras. Python distingue mayúsculas: unidades y Unidades son nombres diferentes.

unidades = 3
unidades = 5
print(unidades)

El último valor asignado es 5. Reasignar no modifica las instrucciones anteriores ni recalcula automáticamente resultados que ya guardaste en otra variable:

unidades = 3
importe_mxn = unidades * 40
unidades = 5
print(importe_mxn)  # Sigue siendo 120

Para obtener 200, ejecuta otra vez el cálculo con el nuevo valor. Esto se conecta con el estado del kernel que observaste en la lección 00.06 — Primer notebook.

2. Tipos: qué clase de dato estás usando

Tipo Ejemplo Uso inicial
str "cuaderno", "3" Texto, incluso si contiene dígitos
int 3, 40 Cantidades enteras
float 1.5 Valores con parte decimal
bool True, False Resultado de una condición
Valor None None Ausencia de un valor; su tipo es NoneType

Puedes consultar el tipo con type(valor):

print(type("3"))  # <class 'str'>
print(type(3))    # <class 'int'>

La salida usa la palabra class para describir el tipo. No necesitas crear clases ni estudiar POO para entender esta comprobación.

Para datos con unidades, explícitalas: importe_mxn no es lo mismo que importe_usd. En esta práctica los importes son enteros. Los decimales tienen límites de precisión; profundizaremos en representación y redondeo cuando haga falta.

3. Texto numérico frente a número

print("3" + "2")  # 32: une dos textos
print(3 + 2)      # 5: suma dos números

Las comillas importan. En los archivos CSV, un lector puede entregar los campos como texto aunque parezcan números. Para calcular, primero debes interpretar su tipo:

unidades_texto = "3"
unidades = int(unidades_texto)
importe_mxn = unidades * 40
print(importe_mxn)  # 120

int(...) convierte texto válido a entero. float("1.5") interpreta un decimal con punto; str(3) produce texto. Convertir no valida todas las reglas del dato: int("-3") es válido para Python, pero puede ser inválido como cantidad de una venta.

No todos los textos se convierten: int("tres") produce ValueError, y int("3.5") tampoco representa un entero válido en ese formato. No intentes resolverlo cambiando datos al azar: revisa qué recibió el programa.

4. Operaciones y comparaciones

Operador Función Ejemplo
+, - Sumar o restar números 80 + 50
* Multiplicar 3 * 40
/ Dividir; produce un float con estos enteros 120 / 3 da 40.0
== Comparar igualdad unidades == 3
>=, < Comparar valores importe_mxn >= 100

= asigna; == compara. Una comparación produce un booleano:

importe_mxn = 120
alcanza_umbral = importe_mxn >= 100
print(alcanza_umbral)  # True

El umbral de 100 es una regla ficticia para practicar comparaciones. En las siguientes lecciones utilizaremos condiciones para actuar sobre comparaciones.

5. Mostrar y explicar el resultado

print(f"{unidades} unidades de {producto}: {importe_mxn} MXN")

La cadena con prefijo f inserta valores entre llaves. print los muestra en la terminal; no crea un archivo de salida. Una explicación debe indicar qué calculaste y sus unidades, además del número.
