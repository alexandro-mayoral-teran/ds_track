# Plantilla de página de módulo

Usa esta plantilla al crear o adaptar el README de un módulo. La estructura y
los criterios están en [la guía de página de módulo](../../docs/module-page-guide.md);
la [referencia aplicada es 00](../../curriculum/00_getting_started/README.md).

Copia el bloque, sustituye todos los campos RUTA/CAMPO y comprueba los destinos
antes de publicar. Los enlaces del bloque son marcadores de plantilla, no rutas
existentes. No crees carpetas vacías para completar apartados ni inventes un
proyecto/checkpoint. El estado de planificación debe quedar explícito.

```markdown
# NN — CAMPO_NOMBRE_DEL_MODULO

[Inicio](RUTA_INICIO) / [Módulos](RUTA_CURRICULUM) / **NN — CAMPO_NOMBRE**

**CAMPO_CAPACIDAD_EN_UNA_FRASE**

[Empezar por NN.01 →](RUTA_PRIMERA_LECCION) · [Lecciones y labs](#lecciones-y-labs) · [Criterio de salida](#criterio-de-salida)

## Propósito
```

Si no existe el módulo siguiente o está planificado, escribirlo con claridad.
Los apoyos o referencias adicionales pueden añadirse al final si aportan valor;
las referencias técnicas detalladas viven principalmente en sus lecciones.
La plantilla define contenido educativo, no genera automáticamente páginas del portal.

Para un módulo planificado, marca los objetivos, evidencias y criterio como
previstos; enlaza el alcance real del plan y muestra los labs como pendientes.
No uses «Empezar la lección» si no existe ni crees archivos para rellenar la tabla.
