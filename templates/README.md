# Plantillas

Plantillas para mantener consistencia al crear módulos y proyectos. Copia la
plantilla adecuada y elimina las secciones que no apliquen; no conserves texto
de ejemplo como si fuera documentación final.

- [`module/`](module/): explicación y ruta de aprendizaje.
- [`lesson/`](lesson/): inicio, desarrollo adaptable y cierre de una lección.
- [`lab/`](lab/): práctica breve de una habilidad.
- [`project/`](project/): integración incremental mediante checkpoints.
- [`github-profile/`](github-profile/): README de ejemplo para tu perfil personal.
- [`learning-project/`](learning-project/): dos bases adaptables para iniciar otro
  proyecto de lecciones: instrucciones de agentes y diseño de arquitectura.
