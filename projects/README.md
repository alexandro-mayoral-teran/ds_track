# Proyectos

Los proyectos integran módulos y producen un resultado compartible.

| Proyecto | Prerrequisitos | Producto |
| --- | --- | --- |
| `01_clean_credit_data` | Python, pandas | Dataset limpio y perfil de calidad |
| `02_credit_database` | SQL, modelado | Base relacional y consultas analíticas |
| `03_portfolio_analysis_r` | R, tidyverse | Análisis visual de cartera |
| `04_large_credit_dataset` | Parquet, Polars, DuckDB | Pipeline y benchmark local |
| `05_monthly_report` | Quarto | Reporte reproducible por corte |
| `06_shiny_portfolio_app` | Shiny, web básico | Explorador interactivo |

Los proyectos de la tabla son planes: se creará cada carpeta cuando se
implemente una práctica integradora con entradas, producto y criterios de salida.
El inicio o cierre del material de un módulo no activa por sí solo su proyecto.
Así se evita mantener esqueletos vacíos.

## Qué falta para implementarlos

La base de lecciones y labs 00–14 está disponible; eso no activa estos proyectos.
La práctica integrada del módulo 14 tiene su propio
[cierre](../docs/reproducible-projects-closure.md). Antes de implementar cada
proyecto de este catálogo, definir pregunta, producto, entradas,
contrato, rúbrica y checkpoints vinculados al material que realmente requiere.
No crear una carpeta vacía solo para representar el plan.

Los criterios de integración pendientes están en
[tidyverse](../docs/tidyverse-closure.md),
[almacenamiento](../docs/storage-closure.md) y
[reportes](../docs/reporting-closure.md). Para la aplicación elegida, consultar
[Streamlit](../docs/streamlit-closure.md) o [Shiny](../docs/shiny-closure.md).
El inventario de lecciones vive en el
[curriculum](../curriculum/README.md), no en este catálogo de proyectos.

Streamlit (12) y Shiny (13) son alternativas antes de 14. Ambas tienen material
y entrega local reconstruible; sus proyectos integradores siguen pendientes.
No se exige construir dos aplicaciones para cerrar el recorrido.

Los proyectos avanzan mediante checkpoints enlazados a lecciones y labs.
Consulta el [flujo de aprendizaje](../docs/learning-workflow.md) y la
[plantilla de proyecto](../templates/project/README.md).
