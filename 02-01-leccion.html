1. Para qué sirve pandas

Con listas y diccionarios aprendiste a representar datos y recorrerlos. pandas ofrece estructuras y operaciones para trabajar con tablas: seleccionar columnas, aplicar reglas, combinar datos y resumirlos. Estas operaciones se introducirán gradualmente; la biblioteca no decide por ti qué significa un registro válido.

Una tabla en pandas vive en memoria. No es una hoja de cálculo con fórmulas en celdas ni una base de datos que guarda cambios automáticamente. Imprimirla muestra una representación; conservarla en un archivo será parte de la siguiente lección.

2. Preparar pandas en tu entorno

Esta lección utiliza pandas 2.3.3 como versión de referencia, comprobada con Python 3.12. No significa que sea la versión más reciente. Se registra en pyproject.toml y uv.lock. Python 3.11 o posterior es el requisito declarado del proyecto.

3. De registros a DataFrame

import pandas as pd

registros = [
    {"producto": "cuaderno", "unidades": 2, "precio_unitario_mxn": 40},
    {"producto": "lápiz, azul", "unidades": 5, "precio_unitario_mxn": 10},
    {"producto": "carpeta", "unidades": 1, "precio_unitario_mxn": 35},
]
tabla = pd.DataFrame(registros)

pd es un alias del módulo. pd.DataFrame(...) construye la tabla a partir de una lista de diccionarios: cada diccionario aporta una fila y sus claves identifican las columnas. tabla es un nombre elegido por nosotros. No necesitas diseñar una clase para utilizar esta estructura.

Índice producto unidades precio_unitario_mxn
0 cuaderno 2 40
1 lápiz, azul 5 10
2 carpeta 1 35

Cada fila representa una venta; unidades y precio describen esa venta. El índice que aparece a la izquierda etiqueta las filas y no cuenta como una de las tres columnas de datos. Su secuencia inicial es 0, 1, 2.

4. Leer la estructura: atributos y métodos

print(tabla.shape)       # (3, 3): filas y columnas
print(tabla.columns)     # Nombres de columnas
print(tabla.index)       # Etiquetas de las filas
print(tabla.dtypes)      # Tipo de cada columna

Estos elementos son atributos: se consultan sin paréntesis. shape es una tupla; su primer componente corresponde a filas y el segundo a columnas. len(tabla) cuenta filas. columns e index son objetos de pandas, no listas comunes; list(tabla.columns) permite mostrar sus elementos como lista.

Un método realiza una operación y se llama con paréntesis, por ejemplo tabla["unidades"].sum(). Usar tabla.shape() produce un error porque intenta llamar a una tupla como si fuera una función.

Qué indican los tipos

En la versión y muestra de referencia:

producto               object
unidades                int64
precio_unitario_mxn     int64

Los tipos describen las columnas. int64 representa enteros; object es un tipo general que aquí contiene texto, pero no garantiza que una columna tenga solo cadenas. En otras versiones o con tipos explícitos puede aparecer un tipo de texto diferente. No memorices la salida como regla universal.

Crear un DataFrame no valida el contrato. Si introdujeras "cinco" entre las unidades, tener una tabla no convertiría ese texto en 5. Conversión, faltantes y reglas se desarrollan después. Tampoco hay que sumar precios unitarios como si fueran el total vendido: el significado de cada medida sigue siendo necesario.

5. Series frente a DataFrame

unidades = tabla["unidades"]        # Series
tabla_unidades = tabla[["unidades"]]  # DataFrame con una columna

print(type(unidades).__name__)      # Series
print(unidades.shape)               # (3,)
print(tabla_unidades.shape)          # (3, 1)
print(unidades.sum())               # 8 unidades

Una Series tiene un eje de etiquetas y un dtype; puede representar una columna y también existir por separado:

unidades_sueltas = pd.Series([2, 5, 1], name="unidades")

Un DataFrame tiene filas y columnas. En tabla[["unidades"]], la lista interior contiene los nombres solicitados, mientras los corchetes exteriores seleccionan. Para varias columnas se usa la misma idea:

vista = tabla[["producto", "unidades"]]  # Forma (3, 2)

La coma de lápiz, azul es parte del texto; aquí no estamos interpretando un CSV. Sumar la columna unidades reproduce el cálculo 2 + 5 + 1 = 8. Cálculos entre columnas y agregaciones más amplias se estudiarán en sus respectivas lecciones.

6. Índice, etiqueta y posición

Las etiquetas pueden ser texto. Creamos una copia para mostrarlo sin cambiar la tabla original:

etiquetada = tabla.copy()
etiquetada.index = ["venta_a", "venta_b", "venta_c"]

print(etiquetada.loc["venta_b", "producto"])  # lápiz, azul
print(etiquetada.iloc[1, 0])                  # lápiz, azul

loc utiliza etiquetas de fila y columna; iloc utiliza posiciones que empiezan en cero. Ambas encuentran el mismo valor en esta tabla, por razones distintas. La posición 1 es la segunda fila; su etiqueta ahora es venta_b.

Si las etiquetas son números, loc continúa interpretándolos como etiquetas, no como posiciones. El índice no garantiza por sí mismo una clave única o estable: estas etiquetas didácticas no sustituyen un identificador de venta de la fuente. Un cambio de orden puede cambiar posiciones sin cambiar las etiquetas. Filtros y selección de conjuntos se profundizan en la lección 03.

Errores frecuentes

Situación Qué revisar
ModuleNotFoundError: pandas Instalación y Python/kernel elegido
KeyError al consultar una columna Nombre exacto y mayúsculas
KeyError en loc La etiqueta solicitada debe existir
IndexError en iloc La posición debe estar dentro de la tabla
Error al asignar index Cantidad de etiquetas igual a cantidad de filas
Tipos inesperados Valores de origen y versión; una tabla no valida por sí sola
