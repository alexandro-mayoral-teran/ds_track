A. Elegir antes de construir — base de la ampliación

Para cada caso, elige función, diccionario o clase/dataclass y justifica:

  1. Calcular una sola cobertura de 2/3.
  2. Recibir un objeto JSON con claves que aún debes validar.
  3. Conservar corte/segmentos para preparar varias solicitudes comparables.
  4. Transformar una tabla de miles de filas con pandas.

Lee CoverageCounts, ReviewOptions y ReviewJob en objetos.py. Describe en una frase la responsabilidad de cada una; identifica qué función conserva el cálculo.

Comprobación: tu decisión responde a una necesidad y al costo añadido. Evidencia: tabla de cuatro decisiones y mapa de tres responsabilidades.

Ver solución razonada de A

Una función basta para la cobertura aislada; un diccionario validado permite inspeccionar el JSON recibido. Una dataclass puede dar nombres estables a opciones que se reutilizan. La transformación tabular conserva pandas y funciones; no necesita una instancia nueva por fila. CoverageCounts reúne dos conteos y delega la operación en coverage_pct; ReviewOptions conserva parámetros validados; ReviewJob compone fuente/opciones y delega el resumen en review_summary. Una decisión diferente es aceptable si explica el beneficio concreto y conserva contratos y resultados.

C. Configuración y composición — práctica

En una sesión nueva python desde el mismo directorio:

from dataclasses import replace
from pathlib import Path
from pandas.testing import assert_frame_equal
from analisis_cartera.objetos import ReviewJob, ReviewOptions
from analisis_cartera.revision import review_summary

source = Path("../../03_sql_databases/01_relational_sqlite/data")
options = ReviewOptions(segments=("educacion", "comercio"))
job = ReviewJob(source, options)
actual = job.summary()
expected = review_summary(source, options.cut, segments=list(options.segments))
assert_frame_equal(actual, expected, check_exact=True)
print(actual[["segmento", "registros", "conocidos", "mediana_mxn", "cobertura_pct"]])
  1. Explica qué objeto contiene a cuál y quién lee los CSV.
  2. Consulta job.options is options. ¿Se duplicaron las opciones al construir job?
  3. Prepara empty_job = replace(job, options=replace(options, segments=())). Compara forma del resumen y opciones originales.
  4. Intenta cambiar options.cut mediante asignación y lee la excepción.
  5. Prueba construir ReviewOptions con cut=None y con segments=[“comercio”]. Explica por qué el contrato de esta configuración difiere de la función de 05.05.

Comprobación: resumen equivalente, orden solicitado y ausencias preservadas; tupla vacía produce (0, 8) sin alterar el original. Evidencia: comparación de tablas, errores identificados y diagrama explicado.

Ver solución razonada de C

job contiene options; summary delega a review_summary, que lee y concilia. La referencia pasada se conserva (is True); es una configuración validada con campos de solo lectura. replace crea instancias nuevas sin modificar las previas. La asignación normal lanza FrozenInstanceError. cut=None y selección como lista se rechazan con TypeError: aquí se almacena texto y tupla; el método adapta esa tupla a la interfaz existente de la función.

Con los CSV originales, educación tiene 3/0 y mediana ausente; comercio 5/5 y mediana 3100. No son las cifras de la fixture pequeña usada en las pruebas.

Ver una solución razonada de D

Agregar dentro de la clase existente, con la misma indentación que los demás métodos:

    def test_replace_de_trabajo_conserva_original(self):
        original = ReviewJob(self.source, ReviewOptions(segments=("comercio",)))
        changed = replace(original, options=replace(original.options, cut="2026-09-30"))
        self.assertEqual(original.options.cut, "2026-10-31")
        self.assertEqual(changed.options.cut, "2026-09-30")
        self.assertEqual(original.summary().iloc[0]["mediana_mxn"], 0.5)
        self.assertEqual(changed.summary().iloc[0]["mediana_mxn"], 900)

replace, ReviewJob y ReviewOptions ya están importados. La fixture de octubre tiene [0, 1, desconocido] en comercio, cuya mediana conocida es 0,5; septiembre contiene un solo saldo 900 en ese grupo. Esta prueba detecta una delegación que ignore el corte de las opciones. No demuestra que futuros CSV sean válidos.
