# Datasets

Las muestras actuales y sus diccionarios se conservan junto a las lecciones que
los introducen. Esta carpeta es el punto de orientación para datos compartidos;
todavía no contiene un catálogo central ni generadores propios.

Puedes comenzar con las [ventas de terminal](../curriculum/00_getting_started/02_terminal_paths/ventas_demo.csv)
o la [muestra y diccionario de pandas 02.02](../curriculum/02_pandas/02_read_inspect_export/README.md#1-una-muestra-nueva-y-su-diccionario).
Las lecciones posteriores enlazan sus fuentes propias o compartidas sin duplicarlas.

Consulta la [política de datos](../docs/data-policy.md) antes de incorporar una
fuente o un generador. Los datos voluminosos se producen localmente con reglas
reproducibles y permanecen fuera de Git. Crear subcarpetas cuando haya contenido
real; una carpeta prevista no significa que sus materiales estén disponibles.
