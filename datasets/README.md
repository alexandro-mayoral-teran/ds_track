# Datasets

Aquí viven muestras pequeñas, generadores y diccionarios del dominio sintético.

La primera versión modelará, como mínimo:

- clientes ficticios;
- créditos;
- fechas de corte;
- saldos;
- pagos;
- días de atraso;
- producto y región artificiales.

Los archivos grandes se generarán localmente con una semilla conocida. Consulta
[`docs/data-policy.md`](../docs/data-policy.md) antes de incorporar cualquier
fuente nueva.
