# Cómo usar la plantilla de perfil

Copia el contenido de [PROFILE.md](PROFILE.md) al `README.md` del repositorio
de tu perfil. Sustituye `TU_NOMBRE` y `TU_USUARIO`, adapta los objetivos y elimina
lo que no te represente. No necesitas copiar este archivo de instrucciones.

La plantilla presenta herramientas como aprendizajes en curso, no como habilidades
ya dominadas. Agrega proyectos y enlaces a medida que tengas resultados que mostrar.
Comprueba la vista previa y abre cada enlace antes de publicar.

El repositorio público del perfil debe tener el mismo nombre que tu usuario.
La práctica completa está en la
[lección del perfil](../../curriculum/00_getting_started/01_github_profile/README.md).
