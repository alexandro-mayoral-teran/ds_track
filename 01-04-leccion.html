Propósito

Separar cálculos, selección y presentación para reutilizar transformaciones sin copiar bloques enteros. Una misma función podrá resumir la colección completa o una selección y devolver datos para seguir trabajando.

Antes de empezar

Completa 01.03 — Condiciones y ciclos y su lab. Usa el mismo entorno de Python sin instalar bibliotecas. Edita y ejecuta desde la raíz de DS Track; las ventas están incluidas en la página y el script. Retoma las referencias y copias de 01.02 para explicar qué ocurre al pasar una colección a una función.

Qué vas a aprender

  • Distinguir definir una función de llamarla y parámetros de argumentos.
  • Usar return para entregar datos y diferenciarlo de print.
  • Separar cálculo, selección y resumen con entradas explícitas y nombres locales.
  • Reutilizar funciones con otra colección, incluida una vacía, y comprobar que conservan las entradas.

1. De un cálculo repetido a una función

Una función agrupa instrucciones bajo un nombre. Permite ejecutar la misma operación con entradas diferentes:

def calcular_importe(unidades, precio_unitario_mxn):
    importe_mxn = unidades * precio_unitario_mxn
    return importe_mxn

resultado = calcular_importe(3, 40)
print(resultado)  # 120
Parte Qué hace
def Define la función
calcular_importe Nombre que expresa su responsabilidad
unidades, precio_unitario_mxn Parámetros: nombres de las entradas
3, 40 al llamarla Argumentos: valores que entregas
Sangría y dos puntos Delimitan el bloque, como en if y for
return Entrega el resultado a quien llamó la función

Definir no ejecuta el cálculo. La llamada con paréntesis lo ejecuta. calcular_importe sin paréntesis refiere a la función, pero no obtiene el importe.

2. print y return tienen propósitos distintos

print muestra información; return entrega un valor para seguir trabajando:

importe = calcular_importe(3, 40)
cumple_umbral = importe >= 100
print(cumple_umbral)  # True

Si tu función solo imprimiera el importe y no tuviera return, la llamada devolvería None. Ver el número en la pantalla no significa que lo hayas recibido como resultado. return también termina esa llamada: las instrucciones posteriores de ese mismo bloque no se ejecutan.

Preferiremos funciones de transformación que devuelvan datos y una parte separada que los presente. Así el mismo resultado puede alimentar una terminal, notebook, reporte o aplicación sin rehacer el cálculo.

3. Llamar con argumentos claros

# Por posición: el orden corresponde a los parámetros
calcular_importe(3, 40)
# Por nombre: deja explícito el significado de cada valor
calcular_importe(unidades=3, precio_unitario_mxn=40)

Los nombres deben coincidir con la definición. Si falta un argumento obligatorio, Python informa TypeError. Revisa la llamada antes de cambiar el cálculo. Una función recibe valores, no sabe por sí sola si sus unidades son correctas.

Un valor predeterminado

def alcanza_umbral(importe_mxn, umbral_mxn=50):
    return importe_mxn >= umbral_mxn

print(alcanza_umbral(80))                 # True: utiliza 50
print(alcanza_umbral(80, umbral_mxn=100))  # False

Aquí se usa un número inmutable como predeterminado. Evita usar [] o {} como valores predeterminados de funciones que los modifican: se crean al definir la función y pueden compartirse entre llamadas. Por ahora pasa las colecciones explícitamente como argumentos.

4. Alcance: dónde existe una variable

Los parámetros y nombres asignados dentro de una función son locales a su llamada:

def calcular_importe(unidades, precio_unitario_mxn):
    importe_local = unidades * precio_unitario_mxn
    return importe_local

resultado = calcular_importe(2, 40)
print(resultado)  # 80

No puedes consultar importe_local desde fuera como si fuera una variable del script: se produciría NameError. Recibe el resultado mediante return. Evita depender de variables globales para hacer un cálculo: declara lo que necesita la función en sus parámetros. Eso permite probarla con otras entradas.

Los argumentos mutables siguen siendo objetos compartidos

Pasar una lista o diccionario no lo copia automáticamente. Una función que modifica sus campos puede afectar el objeto del código que la llamó. Utiliza la copia explícita que aprendiste cuando quieras enriquecer un registro sin modificar las entradas, y documenta esa decisión.

5. Una función por responsabilidad

El ejemplo completo separa tres operaciones:

Función Entrada Resultado
calcular_importe Unidades y precio Número con el importe
seleccionar_ventas Lista de registros y umbral Lista nueva con copias seleccionadas
resumir_ventas Lista de registros Diccionario con cantidad y total

resumir_ventas sirve tanto para toda la colección como para la selección:

general = resumir_ventas(ventas)
seleccionadas = seleccionar_ventas(ventas, umbral_mxn=50)
filtrado = resumir_ventas(seleccionadas)

Para las tres ventas conocidas, general contiene cantidad 3 y total 165; filtrado contiene cantidad 2 y total 130. La función devuelve datos, no imprime ese resumen. Con una colección vacía devuelve cantidad 0 y total 0.

Coloca return después del ciclo cuando quieras recorrer todos los registros. Si lo pones dentro sin una condición que lo justifique, podrías terminar en la primera venta. La sangría también cambia el resultado de una función.

Estos ejemplos suponen campos numéricos presentes. Convertir y validar entradas será una responsabilidad explícita en las siguientes lecciones.

6. Documentar sin repetir todo el código

La cadena al principio de una función, llamada docstring, explica su contrato:

def calcular_importe(unidades, precio_unitario_mxn):
    """Calcula el importe con entradas numéricas ya preparadas."""
    return unidades * precio_unitario_mxn

Describe qué recibe, qué devuelve y supuestos importantes. Un nombre claro y una explicación breve ayudan más que un comentario que repita cada operador.

La última condición del archivo

if __name__ == "__main__": llama a main cuando ejecutas ese archivo directamente. Si otro programa importa sus funciones, no ejecuta automáticamente la demostración. Es una convención útil; estudiaremos las importaciones con más detalle al organizar la lectura y transformación de archivos. No necesitas memorizarla para calcular.
