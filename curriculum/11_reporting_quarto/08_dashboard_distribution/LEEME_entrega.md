# Lectura del dashboard

Abre `dashboard.html` en un navegador. Incluye tres créditos ficticios en los
cortes 2026-09-30 y 2026-10-31; los saldos están en MXN. La diferencia es octubre
menos septiembre y la variación usa septiembre como base. Con base cero no
está definida. No son datos reales ni pagos del período.

Las pestañas Figura y Detalle cambian la vista de datos ya incluidos; no
ejecutan Python/R ni consultan una fuente nueva. No hay filtros ni servidor.
La lectura requiere JavaScript para las pestañas de este dashboard Quarto.
El HTML de esta práctica incorpora imagen, CSS y scripts de lectura.

Comprueba que ambas vistas y las columnas de la tabla se pueden leer. El dato
se actualiza al regenerar el archivo, no al abrirlo. Este paquete contiene el
HTML y esta nota; no incluye todos los fuentes ni el entorno para reconstruir.
Conserva por separado CSV, funciones, documento y CSS si necesitas reproducir.

Si la copia no abre correctamente o faltan valores, conserva el archivo y
solicita una entrega revisada; no inventes cifras ni cambies solo su nombre.
