# 05 — Python aplicado

**Estado del material:** planificación. Las lecciones y labs aún no están desarrollados.

## Ubicación en el recorrido

Después de Python, pandas, SQL y visualización básica. Se reutiliza el mismo
análisis para aprender a organizarlo antes de reproducirlo en R.

## Contenido previsto

Módulos y funciones reutilizables; configuración y logging; clases, composición y dataclasses; anotaciones de tipos; generadores y decoradores; pruebas y gestores de contexto; rendimiento e integración con APIs.

El núcleo para avanzar es separar responsabilidades, reutilizar funciones y
comprobar resultados. Clases y dataclasses se practican cuando aportan claridad;
crear decoradores, profiling y APIs son profundización. Concurrencia y
metaprogramación no son requisitos para pasar al módulo de R.
