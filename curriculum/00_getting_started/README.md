## Propósito

Preparar un entorno desde el que puedas realizar las siguientes prácticas de datos.
Empiezas documentando una presentación y terminas ejecutando un script y un
notebook, con archivos que puedas conservar, retomar y explicar.

## Antes de empezar

| Preparación | Qué necesitas al iniciar |
| --- | --- |
| **Conocimientos** | No se requiere experiencia previa con terminal o programación |
| **Herramientas iniciales** | Editor de texto y una forma de previsualizar Markdown |
| **GitHub, si eliges publicar** | Una cuenta para la práctica recomendada del perfil |

Python, Git, entornos y notebooks se presentan cuando hacen falta; no instales
por adelantado todos los gestores. Las lecciones indican dónde ejecutar cada paso.
Puedes estudiar con una copia descargada y practicar Git si eliges ese recorrido.

## Qué vas a aprender

- Escribir y previsualizar una presentación en Markdown, distinguiendo texto y formato.
- Ubicar archivos y explicar la diferencia entre tu copia local, Git y GitHub.
- Ejecutar y modificar un script Python, contrastando el resultado.
- Preparar un entorno y elegir el kernel para ejecutar un notebook desde cero.

## Cómo trabajar este módulo

1. Lee una lección y escribe tu predicción antes de ejecutar.
2. Haz su lab en tu propia copia; compara resultado y reglas.
3. Explica lo que comprobaste y guarda tu evidencia antes de continuar.

En pareja, una persona realiza y explica la práctica; la otra observa y pregunta.
Cambien de papeles al completar un bloque. No editen simultáneamente la misma copia.

> **A tu ritmo:** una sesión puede cubrir solo parte de una lección. En 00.05
> trabaja primero A y después B, eligiendo un solo recorrido: Conda, venv/pip o uv.
> Las otras opciones no son ejercicios adicionales obligatorios.

## Qué conservar

| Evidencia personal | Qué permite revisar |
| --- | --- |
| README de presentación | Formato, enlaces y objetivos propios; perfil publicado si lo elegiste |
| Nota del lab de rutas | Desde qué carpeta trabajaste y cómo encontraste los archivos |
| Script modificado | Entrada, resultado previsto y resultado observado |
| Instrucciones del entorno | Qué Python/bibliotecas usaste y cómo reconstruirlo |
| Notebook guardado | Ejecución completa desde un kernel limpio |
| Nota de reflexión | Explicación, ayudas recibidas, dudas y siguiente paso |

Puedes copiar la [bitácora de 00](../../templates/learning-session/bitacora-00.md)
a tu carpeta personal. La nota acompaña tus archivos; no demuestra por sí sola
aprendizaje. PROGRESS.md conserva el estado editorial del curso.

## Criterio de salida

Puedes continuar cuando reproduzcas las prácticas y expliques sus decisiones:

- Previsualizas tu README y explicas qué cambió respecto al texto fuente.
- Ubicas tu copia y ejecutas el script desde la carpeta indicada, justificando el resultado.
- Reconoces el entorno y kernel elegidos y ejecutas tu notebook desde una sesión limpia.

Si elegiste publicar el perfil o practicar Git, comprueba también esos pasos.
Si hay una diferencia, identifica qué revisarías antes de repetir; no basta con
guardar el archivo. Este módulo no tiene un checkpoint de proyecto implementado.
