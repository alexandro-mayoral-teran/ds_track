# 13 — Shiny y fundamentos web

Introducir cliente, servidor, HTML, CSS y reactividad antes de construir una
aplicación Shiny para explorar la cartera sintética.

## Dos rutas de aplicación planificadas

| Ecosistema | Herramienta | Conceptos |
| --- | --- | --- |
| R | Shiny | UI, servidor, reactividad, estado y módulos |
| Python | Streamlit | Inputs, tablas, gráficas, reejecución, estado y caché |

Este módulo es la ruta de aplicación en R; Streamlit ocupa el nivel 12.
Se elegirá una para el producto; no es obligatorio implementar ambas.
Prerrequisito: análisis y gráficas estables con indicadores verificables.

Matplotlib, Altair y ggplot2 producen gráficos; Shiny y Streamlit construyen
aplicaciones que los presentan. Ambas rutas separarán transformaciones y
validación de la interfaz. Sus lecciones y labs aún no están implementados.
