# 06 — Arrow y Parquet

Comprender esquemas, representación columnar, compresión, row groups,
particionamiento y lectura selectiva. Se trabajará desde Python y R para mostrar
la interoperabilidad del formato.

Primero se leerán y escribirán archivos pequeños, comprobando tipos, filas e
indicadores. El particionamiento se introducirá cuando tenga una justificación;
evolución de esquemas y problemas de archivos pequeños quedan como profundización.
