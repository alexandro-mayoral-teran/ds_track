# 03 — SQL y bases de datos

Pasar de archivos a tablas relacionadas. El módulo cubrirá diseño, restricciones,
consultas, joins, CTE, ventanas, transacciones e índices, comenzando con SQLite y
dejando PostgreSQL como extensión.

Primero se estudiarán selección, filtros, agregaciones y joins. Índices y planes
de consulta se profundizarán cuando exista una limitación concreta.
El cierre integra Python, pandas y SQLite sobre datos conocidos, concilia un
indicador y explica una gráfica antes de cambiar de lenguaje en el módulo de R.
