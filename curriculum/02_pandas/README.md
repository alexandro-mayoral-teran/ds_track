# 02 — pandas

Construir el modelo mental de DataFrame y practicar selección, tipos, faltantes,
duplicados, fechas, agregaciones, uniones y reshape. El resultado alimentará el
primer proyecto de limpieza de cartera.

Desde este módulo se comunicarán resultados con una gráfica sencilla y una
interpretación escrita. Se comprobarán filas, llaves y totales al transformar
y unir tablas; la comunicación y calidad no se posponen hasta el proyecto final.

## Visualización prevista

Matplotlib será la base para una primera gráfica: Figure/Axes, elección entre
barras o líneas según la pregunta, etiquetas, unidades e interpretación.
El nivel 04 profundizará en diseño e interacción con Altair sobre datos
ya comprobados en la [ruta de visualización](../../docs/architecture.md#visualización-entender-antes-de-construir-aplicaciones).
Estos contenidos están planificados; las lecciones detalladas aún no existen.
